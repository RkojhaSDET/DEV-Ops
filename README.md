# DEV-Ops
Road MAp for Dev-Ops 

3 Month roadMap to get into devops 

Month 1: Foundations & Core Tools

Week 1: DevOps & Version Control

Daily Routine:

Day 1–2: Read about DevOps lifecycle, culture, and practices (Source: "The DevOps Handbook")

Day 3: Compare SDLC and DevOps models

Day 4–5: Study CI/CD basics via FreeCodeCamp or KodeKloud

Day 6–7: Learn Git (clone, commit, push, pull, merge, branching) with GitHub (Source: Git official docs, Codecademy)

Week 2: Linux & Shell Scripting

Daily Routine:

Day 1–2: Learn Linux file system, users, and permissions (Source: LinuxCommand.org)

Day 3–5: Practice common shell commands

Day 6–7: Write basic bash scripts using WSL or a VM (Ubuntu)

Week 3: Jenkins CI

Daily Routine:

Day 1–2: Install Jenkins (local/cloud)

Day 3–4: Create freestyle and pipeline jobs

Day 5: Connect GitHub to Jenkins (Source: Jenkins.io tutorials)

Day 6–7: Build and deploy a Maven-based Java project

Week 4: Build Tools & Integration

Daily Routine:

Day 1–2: Study Maven/Gradle fundamentals

Day 3–4: Integrate Jenkins with Maven

Day 5–7: Create automated builds with Jenkins triggers (Source: Baeldung Maven guides)

Month 2: Containers & Orchestration

Week 5: Docker

Daily Routine:

Day 1–2: Install Docker, run basic containers

Day 3–4: Learn Dockerfile and Docker Compose (Source: Docker Docs, Katacoda)

Day 5–6: Build and push images to DockerHub

Day 7: Docker practice challenge (e.g., Dockerlabs)

Week 6: Kubernetes

Daily Routine:

Day 1–2: Study K8s architecture

Day 3–4: Install Minikube or use Play with Kubernetes

Day 5–6: Deploy a containerized app

Day 7: Practice with kubectl commands, Services, Deployments (Source: Kubernetes.io tutorials)

Week 7: Jenkins Pipelines (Advanced CI/CD)

Daily Routine:

Day 1–3: Learn declarative pipeline syntax

Day 4–5: Set up webhooks and shared libraries

Day 6–7: Deploy a Docker app to K8s using Jenkins pipeline

Week 8: Infrastructure as Code (IaC)

Daily Routine:

Day 1–2: Intro to Terraform (providers, resources)

Day 3–4: Launch EC2 using Terraform

Day 5–7: Deploy basic infra with Terraform modules (Source: Terraform.io tutorials)

Month 3: Cloud, Monitoring & Projects

Week 9: AWS Cloud Services

Daily Routine:

Day 1–2: Learn IAM, EC2, S3 basics (Source: AWS Free Tier & AWS Skill Builder)

Day 3–4: Launch and connect to EC2

Day 5–7: Deploy app on EC2 manually and with Terraform

Week 10: Monitoring and Logging

Daily Routine:

Day 1–3: Install and configure Prometheus + Grafana for Docker/K8s

Day 4–5: Learn ELK Stack basics

Day 6–7: Collect logs from containers using Filebeat/Logstash

Week 11: Security and Secrets Management

Daily Routine:

Day 1–2: Learn IAM policies and roles in AWS

Day 3–4: Use Vault or AWS KMS for managing secrets

Day 5–7: Secure Jenkins credentials and pipeline secrets

Week 12: Capstone Project

Daily Routine:

Day 1–3: Build full CI/CD pipeline: GitHub -> Jenkins -> Docker -> K8s -> AWS

Day 4–5: Add monitoring (Grafana/Prometheus) and logging (ELK)

Day 6: Document the architecture

Day 7: Push everything to GitHub and share
